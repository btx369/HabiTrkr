# Privacy Policy

## Data Storage
This application stores all user data locally on your device using browser localStorage. **No data is ever transmitted to external servers or stored in the cloud.**

## Data Types Stored Locally:
- **Notes**: Text, list, audio, and image notes
- **Events**: Personal events and reminders  
- **Habits**: Habit tracking data and completion records
- **Clock Settings**: Alarms, world clocks, timer/stopwatch preferences

## Data Retention:
- Data persists until manually deleted by the user
- Data is retained when switching between app sections
- No automatic cleanup or expiration policies
- Clearing browser data will remove all stored information

## Privacy Guarantee:
- No external APIs or servers are contacted for data storage
- No analytics or tracking implemented
- No user identification or profiling
- Complete offline functionality

Your privacy is protected through local-only data storage.
