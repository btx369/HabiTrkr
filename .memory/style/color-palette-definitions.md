# Memory: style/color-palette-definitions

The global color palette (src/constants/colors.ts) contains 12 colors organized warm-to-cool with neutrals at the end:

| # | Color Name | Hex Code |
|---|------------|----------|
| 1 | White (default) | `#FFFFFF` |
| 2 | Light Yellow | `#FEF3C7` |
| 3 | Light Orange | `#FED7AA` |
| 4 | Light Red | `#FCA5A5` |
| 5 | Coral Red | `#F87171` |
| 6 | Light Mint | `#A7F3D0` |
| 7 | Mint Green | `#86EFAC` |
| 8 | Light Blue | `#BFDBFE` |
| 9 | Sky Blue | `#93C5FD` |
| 10 | Light Purple | `#DDD6FE` |
| 11 | Periwinkle | `#C4B5FD` |
| 12 | Light Gray | `#9CA3AF` |

Colors are paired (light/darker variants): Yellow-Orange, Red-Coral, Mint-Green, Blue-Sky, Purple-Periwinkle. Gray stands alone as a neutral. This palette is used consistently across all Note, Event, Habit, and Folder editors via the ColorPicker component.
